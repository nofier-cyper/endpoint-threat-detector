# Endpoint Threat Detector

A defensive endpoint security tool for detecting suspicious processes,
network activity, persistence indicators, and file characteristics.

## Project Goal

Endpoint Threat Detector is a cybersecurity learning project designed
to help analyze potentially suspicious activity on an authorized system.

The project focuses on practical defensive security concepts such as:

- Process monitoring
- Network activity analysis
- Persistence detection
- File hashing
- Risk scoring
- Security reporting

## Version

Current version: v0.1

## Project Status

🚧 Under active development.

## Safety

This project is designed for defensive and authorized security testing.

It does not provide unauthorized access, remote control, credential theft,
or malware deployment capabilities.

## Planned Features

- Process analysis
- Network connection analysis
- Suspicious file detection
- Persistence checks
- SHA-256 file hashing
- Detection rules
- Risk scoring
- JSON security reports
- Automated tests

- Operating system security concepts
